# QQBotGPT

在 QQ 中使用自己的 ChatGPT 或 DeepSeek。支持私聊、群内 @、连续追问、独立会话记忆，以及 ChatGPT 网页搜索、图片理解和文件阅读。程序运行在自己的电脑或服务器上，通过 QQ 官方机器人接口接收消息并回复文字。

另提供 [微信 ClawBot 私聊入口](docs/微信接入.md)：多个微信号分别扫码，分别保存记忆和模型设置，复用现有模型服务。微信入口仅接受扫码账号的私聊，支持文字及 ChatGPT 图片、文件输入，不接入群聊。

## 功能

- **两种模型服务**：使用官方 Sign in with ChatGPT 登录，或配置自己的 DeepSeek API Key；可以在 QQ 中切换。
- **按会话管理**：私聊和各个群分别绑定，分别保存模型、思考强度和聊天记忆，重启后恢复。
- **群成员使用**：默认只响应绑定账号；可开放已绑定群的所有成员 @提问，设置仍由绑定账号管理。
- **按需搜索**：ChatGPT 遇到实时信息或联网请求时调用网页搜索。聊天默认隐藏来源，索要出处时再附网址。
- **图片和文件**：QQ、微信每轮最多带两张图片或一个文件；明确引用可重读，普通追问只带文字上下文。
- **适合 QQ 阅读**：回复转换为纯文本，保留段落、普通列表和代码缩进。
- **可长期运行**：SQLite 保存状态，支持 Linux systemd 服务和登录凭据续期。

文字聊天已在 Windows 本机、Linux 服务器、QQ 群聊及私聊中完成实际验证。图片和文件流程已覆盖模拟回归测试，真实通道验收需使用部署账号发送附件。语音、视频和工具执行尚未接入。自动接话默认关闭。

## 准备

- Python 3.10 或更新版本，以及 Git；也可以从仓库页面下载 ZIP。
- 自己创建的 [QQ 官方机器人](https://q.qq.com/)，以及它的 AppID 和 AppSecret。在 QQ 开放平台配置 WebSocket，并开放需要使用的群聊或私聊场景。
- 选择一种模型服务：符合 [Sign in with ChatGPT 接入条件](https://developers.openai.com/siwc/quickstart)的 ChatGPT 账户，或自己的 DeepSeek API Key。模型和网页搜索的可用性以账户实际授权结果为准。

QQ 凭据负责收发消息，模型服务负责生成回答。本项目为独立开源项目。

## 快速开始

### 1. 下载并安装

```bash
git clone https://github.com/aofenghanyue/QQBotGPT.git
cd QQBotGPT
python -m venv .venv
```

Windows PowerShell：

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item config.example.json config.json
```

Linux / macOS：

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
cp config.example.json config.json
```

系统仅提供 `python3` 时，创建环境的命令改为 `python3 -m venv .venv`。如果 PowerShell 禁止激活环境，可用 `.\.venv\Scripts\python.exe` 代替后续命令中的 `python`。

### 2. 配置 QQ 和模型服务

编辑 `config.json`，填写 `app_id` 和 `app_secret`，然后选择一种模型服务。

**ChatGPT**：保持 `"provider": "chatgpt"`，在当前电脑登录并测试：

```bash
python chatgpt.py login
python bot.py --test-model
```

浏览器会打开官方登录页面，请完成登录和额度授权。终端显示登录成功后，连接测试应返回模型信息和“连接成功”。`chatgpt_model` 留空时使用账户返回的第一个可用模型；`python chatgpt.py models` 可查看列表。

**DeepSeek**：将 `provider` 改为 `deepseek`，在项目中创建 `.data` 目录和 `.data/deepseek.key` 文件，只写入自己的 API Key，然后运行：

```bash
python bot.py --test-model
```

默认模型为 `deepseek-flash`，可以通过 `deepseek_model` 修改。两种服务可以同时配置，之后在 QQ 中切换。

### 3. 启动并绑定

```bash
python bot.py --bind
```

用自己的 QQ 私聊机器人，或在目标群里 @机器人，发送终端显示的 `/绑定 …` 口令。口令 10 分钟内有效，只能使用一次。收到“绑定成功”后即可提问：

```text
你好，帮我整理一下今天的待办。
联网查一下 Python 官网目前推荐的稳定版，简短回答。
```

群内发送问题和命令时请 @机器人。绑定、模型设置和记忆会保存，以后启动只需运行 `python bot.py`。同一个 QQ 机器人同时运行一个实例。

### 4. 新增群和开放群成员使用

机器人运行期间，在同一项目目录另开终端：

```bash
python bot.py --new-binding
```

在尚未绑定的新群中 @机器人并发送生成的口令，服务无需停止。每次口令仅用于一个新群，新生成的口令会替换上一条未使用的口令。

需要让已绑定群的其他成员 @提问时，将 `group_members_can_chat` 改为 `true`，然后重启。修改模型、思考、记忆设置和清空记录仍限该会话的绑定账号。私聊继续只响应绑定账号。

## QQ 命令

| 命令 | 作用 |
| --- | --- |
| `/帮助` | 查看命令说明 |
| `/状态` | 查看当前模型、连接、记忆和最近一次搜索次数 |
| `/模型` | 查看当前会话的模型服务和名称 |
| `/模型 列表` | 列出当前服务的可用模型 |
| `/模型 列表 chatgpt` | 列出 ChatGPT 可用模型；也可填写 `deepseek` |
| `/模型 chatgpt <模型名>` | 切换当前会话的 ChatGPT 模型 |
| `/模型 deepseek deepseek-flash` | 切换当前会话到 DeepSeek |
| `/模型 默认` | 恢复配置文件中的模型选择 |
| `/思考` | 查看当前思考设置及可选项 |
| `/思考 高` | 设置当前会话的思考强度 |
| `/思考 默认` | 恢复默认思考设置 |
| `/超时` 或 `/等待` | 查看当前会话的模型等待上限 |
| `/超时 240` | 设置等待上限，范围 30～240 秒 |
| `/超时 默认` | 恢复配置文件或服务原有的等待上限 |
| `/记忆` | 查看记忆容量与过期时间 |
| `/记忆 200` | 保留最近 200 条消息 |
| `/记忆 过期 360` | 连续闲置 360 分钟后清除记忆；`0` 表示不过期 |
| `/清空` | 清除当前会话的聊天记录，保留设置 |

模型名请从账户实际列表中选择，思考档位以 `/思考` 的返回内容为准。设置从下一次请求生效，重启后保留。命令不会生成模型回答；查询模型列表需要访问对应服务。

私聊和群内 @ 提问处理满一分钟仍未完成时，会先回复一次“正在思考，请稍等。”，随后补发完整回答；达到上限会取消本次调用并提示超时。等待提示不进入聊天记忆，不延长总时限。群聊被动回复的有效期为五分钟，因此程序还会扣除排队耗时并预留发送时间；拥堵时实际可等待时间可能短于设置值。自动接话不发送等待提示。修改等待上限的权限与其它会话设置一致。

QQ 发送失败时会将当次回答和错误详情保存在私有诊断记录中，最多保留七天、一百条；`/清空` 同步删除当前会话的诊断记录。管理员可通过 `python diagnostics.py --data-dir /path/to/data --limit 5` 只读查看，具体说明见[发送失败排查](docs/常见问题.md)。这些记录包含聊天正文，应与登录和记忆数据一样限制访问。

### DeepSeek 思考过程

切换到 DeepSeek 后发送 `/思考 开启`，或用 `/思考 高`、`/思考 强度 最高` 选择强度。QQ 收到模型响应后，会先发送接口实际返回的思考过程，再单独发送最终回答；`/思考 关闭` 后只发送回答。思考过程按需拆成最多三条消息，每条不超过 3000 字符，过长时明确标注省略；加上等待提示和最终回答，每个问题最多使用五次回复。

思考过程不写入聊天记忆、不回传到后续模型请求。思考消息发送失败时保存诊断，并继续尝试发送最终回答；接近回复时限时优先发送回答。当前采用模型完成后发送的方式，微信入口仍保持原有的回答展示。参数说明见 [DeepSeek 官方思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)。

## 图片和文件阅读

使用 ChatGPT 模型时，可以在 QQ 私聊、群内 @ 或微信私聊发送图片、文件。支持图片 PNG、JPEG、WEBP、GIF，以及 PDF、Word、Excel、PowerPoint、CSV、TSV、常见文本和代码文件；单个附件最多 20 MiB。文件与图片的具体读取能力取决于账户所选模型，非 PDF 文档中的嵌入图片和图表可能无法完整解析。DeepSeek 入口仍提供文字对话，发送附件时会提示切换到 ChatGPT。

- 附件与问题在同一条消息时直接分析；单独发送附件时先确认收到，再在 5 分钟内紧接着发送文字问题。QQ 群内使用 @，且平台需实际下发附件消息。
- 连续发送图片只保留最近两张，连续发送文件只保留最近一个。图片和文件混合时，以最后收到的附件类型为准，单轮上限保持为两张图片或一个文件。
- 附件用于下一轮问题后移出待处理区。后续普通追问保留文字上下文，不重复上传原附件。命令会取消同一发送者待处理的附件。
- 回复引用原附件消息、写出准确文件名，或明确说“上一张图”“刚才的两张图片”“刚才的文件”，可再次读取对应附件。明确引用的附件优先于无关的待处理或新发文件；新图与被引用的旧图可在两张上限内一起比较。多个同名附件需要用回复引用指定。链接过期、引用无法定位时会提示重新发送。
- 待处理附件只在内存中保存引用；重启后需要重新发送或明确引用。用于明确引用的索引最多保留最近 24 小时、每个机器人数据库最近 200 条附件消息，包含平台下载地址、文件名和微信解密信息。原始附件只在请求期间下载到内存，不写进聊天历史，不在本机另存附件文件。
- 附件索引按会话、发送者隔离。平台直接提供被引用附件内容时使用该次引用；自动按文件名或最近附件查找只查询发送者自己的索引。`/清空` 同时清除当前会话的附件引用。记忆闲置到期也会清理。

## 网页搜索和聊天记忆

ChatGPT 默认按需使用官方 `web_search` 工具，可以直接说“联网查一下……”。普通聊天按需要直接回答。默认回复只显示正文，明确要求“附上来源”或“给我网址”时再显示出处；`/状态` 中的次数来自实际工具调用。

搜索沿用已登录的 ChatGPT 计划，无需额外搜索 API Key，可能增加等待时间和用量。`chatgpt_web_search` 可关闭搜索，`chatgpt_show_sources` 可设置始终显示来源，修改后重启。DeepSeek 当前提供文字对话。

默认保存最近 100 条消息，连续 6 小时没有新消息后清除。提问时，相关上下文发送给所选模型。群成员共享本群记忆，私聊和其他群保持独立。开放群成员使用后，模型请求使用部署者的凭据和额度。

配置、登录和聊天记录保存在运行设备上，`config.json`、`.data/`、密钥与日志已加入 Git 忽略规则。共享配置示例或问题日志时，请使用脱敏内容。
