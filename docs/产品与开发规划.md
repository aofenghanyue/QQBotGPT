# 产品与开发规划

QQBotGPT 面向能自行部署程序的个人用户。程序运行在用户自己的电脑或服务器，连接自己的 ChatGPT 或 DeepSeek，通过 QQ 私聊和群内 @完成文字问答。

## 已完成范围

- QQ 私聊、群内 @、一次性绑定和可配置的群成员提问权限。
- ChatGPT 官方登录、模型调用和按需网页搜索，以及 DeepSeek 文字对话。
- QQ、微信图片理解和文件阅读；每轮最多两张图片或一个文件，明确引用可重读。
- 按会话切换模型、设置思考强度、保存和清除记忆。
- 适合 QQ 的纯文本回复，支持连续追问和重启恢复。
- 本机启动、Linux systemd 部署、登录迁移及自动化测试。
- 中文安装与维护文档、示例配置和 0BSD 许可证。

实现和验证结果见 [开发记录](开发记录.md)。

## 后续方向

优先处理来自实际部署的兼容性和可靠性问题，保持配置简单、运行依赖精简。

1. 补充更多 QQ 平台事件和服务异常的回归案例。
2. 根据首次部署反馈完善登录、绑定和故障排查说明。
3. 观察模型列表、思考档位及搜索接口变化，维护官方接口兼容性。

语音、视频、管理网页和工具执行暂不在当前版本范围内。新增能力会先明确需求、权限和验证方式，再安排实现。

## 验收重点

- 提问可以收到回答，连续追问能使用当前会话上下文。
- 私聊和不同群的记忆独立，重启可恢复，清空命令只影响当前会话。
- 未绑定会话在默认模式下不调用模型，群成员权限和管理权限分别生效。
- 登录、额度、模型能力和网络异常能给出可操作的提示。
- 新使用者可以依据文档配置自己的账户和 QQ 机器人，无需修改源码。
