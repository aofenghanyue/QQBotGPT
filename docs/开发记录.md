# 开发记录

记录公开版本的主要变化和实际验证范围。安装流程见 [README](../README.md)，服务器运行见 [服务器部署](服务器部署.md)。

## 2026-10-28：QQ 展示 DeepSeek 思考过程

- DeepSeek 开启思考时保留接口返回的 `reasoning_content`，QQ 在模型响应完成后先展示思考过程，再发送最终回答。
- 长思考分为最多三条消息，超过容量时标记省略；与等待提示、最终回答共用最多五次回复，发送前检查剩余回复时间。
- 思考内容与最终回答分开处理，聊天记忆和后续请求只保留最终回答。思考消息失败时保存诊断并继续尝试发送回答。
- 增加分段与长度限制、回复序号、思考发送失败、聊天记忆隔离和自动接话静默的回归测试。
- 本地 Windows 和服务器 Ubuntu 均通过 144 项自动化测试。

## 2026-10-27：QQ 发送失败诊断

- 发送失败时保存实际发送文本、可用的模型原文、HTTP 状态、QQ 错误响应和追踪 ID，区分等待提示、命令回复与回答。
- 诊断数据保存在私有 SQLite 数据库中，保留七天、最多一百条；限制单条大小并脱敏错误详情中的凭据。普通日志只记录诊断编号，失败回答不进入聊天记忆。
- 增加 `diagnostics.py` 管理员只读查询入口，显式 `/清空` 同步删除本会话诊断。
- 回归测试覆盖 API 拒绝、非 JSON 错误、网络故障、等待提示超时、落盘失败、清理、脱敏与读取兼容性。
- 本地 Windows 与服务器 Ubuntu 均通过 138 项自动化测试，依赖一致性检查通过；发送失败场景使用模拟接口验证。

## 2026-10-22：QQ 等待提示与可调超时

- 增加 `/超时` 和 `/等待` 命令，按会话保存 30～240 秒的等待上限，并支持恢复默认。
- 明确提问的模型请求满一分钟仍未完成时先发送一次等待提示，随后补发完整回答；到达总时限取消调用，排队时预留 QQ 回复窗口。
- 增加持久化、权限、分阶段发送、发送失败、超时取消与退出清理测试；本地和服务器均通过当时的 128 项测试，服务器真实模型连接验证成功。

## 2026-10-19：QQ 与微信图片、文件输入

- 增加共享附件处理模块，接入 QQ 附件和微信 CDN 下载、AES 解密，通过 ChatGPT Responses 的内联图片/文件输入完成分析。
- 每轮最多读取最近两张图片或一个文件；待处理附件在下一轮使用后移出。普通追问保留文字上下文，明确回复引用、文件名或最近附件指代可重新读取对应内容。
- 引用优先于无关的新文件；索引按会话和发送者隔离，限制保留时间与数量，清空聊天同步删除引用。原始附件不写入聊天记忆。
- 增加选择上限、历史不重复上传、明确引用、解密、权限、下载失败及发送重试的回归测试，并更新两端帮助和部署文件清单。
- 本次验证覆盖本地模拟接口与真实 AES 解密；本机 ChatGPT 登录已转交服务器，真实 QQ/微信附件与账户模型输入仍需在部署环境验收。

## 2026-10-18：首次公开版本

### QQ 文字聊天与模型接入

- 整理 QQ WebSocket 收发、消息去重、私聊和群内 @处理。
- 接入官方 Sign in with ChatGPT 登录、身份校验、凭据续期、模型列表与 Responses 文字回答。
- 支持 DeepSeek API Key 和模型服务切换。
- 加入一次性本人绑定；私聊与各个群独立保存绑定和 SQLite 聊天记忆。
- 提供登录导出、导入及独立设备标识，配套 Linux systemd 服务模板。

本机完成 ChatGPT 真实调用及 QQ 群聊、私聊验证。Linux 服务器分别调用 ChatGPT 和 DeepSeek，并通过 QQ 实际收发。凭据续期与轮换通过模拟响应测试；初次部署使用仍有效的凭据，未触发真实续期。

### 群成员和会话设置

- 新增 `group_members_can_chat`，可允许已绑定群的所有成员 @提问；设置修改限绑定账号。
- 新增 `/模型` 和 ChatGPT `/思考`，按会话保存选择，模型与档位按账户返回结果校验。
- 新增 `--new-binding`，机器人运行期间可以生成新群口令，10 分钟有效且单次使用；数据库仅保存摘要。
- 实际新增群绑定完成，其他群成员 @提问收到回答；ChatGPT 和 DeepSeek 切换及思考设置通过真实调用验证。

### QQ 纯文本

为两种模型服务统一加入纯文本要求，发送前转换常见 Markdown 标记。代码片段保留内容和缩进，群聊、私聊与保存的助手回复使用同一结果。两种服务均通过要求标题、加粗和代码的真实调用验证。

### ChatGPT 网页搜索

启用官方 `web_search` 工具，按问题需要搜索。回复默认隐藏引用来源，明确索要出处时再显示，支持 `chatgpt_web_search` 和 `chatgpt_show_sources` 配置。`/状态` 显示最近一次实际检索或网页读取次数。

补齐 `response.output_item.done` 收集，兼容最终 `response.completed` 中 `output` 为空的流式响应；只有成功完成后才发送最终回答。引用从工具返回的网址注释提取、校验与去重。

真实请求完成搜索和官网读取；普通聊天测试的工具调用次数为 0。QQ 群内实测记录了检索、网页读取与发送成功，确认收到正常回答且默认未附来源。
