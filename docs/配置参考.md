# 配置参考

首次安装从 [config.example.json](../config.example.json) 复制出 `config.json`，以 UTF-8 保存。JSON 使用双引号和 `true` / `false`，不支持注释或末尾多余的逗号。

## 基本配置

| 字段 | 示例默认值 | 含义 |
| --- | --- | --- |
| `app_id` | `""` | QQ 机器人 AppID，必填 |
| `app_secret` | `""` | QQ 机器人 AppSecret，必填 |
| `provider` | `"chatgpt"` | 默认服务，支持 `chatgpt` 或 `deepseek` |
| `chatgpt_model` | `""` | ChatGPT 模型名；留空采用账户列表中的第一个可用模型 |
| `chatgpt_web_search` | `true` | 为 ChatGPT 提供官方网页搜索工具，由模型按需调用 |
| `chatgpt_show_sources` | `false` | 是否始终显示网页来源；为 `false` 时，明确索要出处仍会显示 |
| `auto_model` | `false` | 按会话默认开启自动模型与思考强度选择 |
| `auto_reply_decision` | `false` | 自动接话前通过 Decisions 快速判断；与模型选择开关独立 |
| `openai_key_file` | `".data/openai.key"` | 仅包含 OpenAI API Key 的 UTF-8 文件；优先使用 `OPENAI_API_KEY` 环境变量 |
| `decision_timeout_seconds` | `5` | 候选列表与快速决策共用的等待上限，1～15 秒 |
| `auto_reply_threshold` | `0.8` | 接话评分达到此阈值才生成回复，范围 0.5～1；需结合实际群聊调整 |
| `auto_model_max_effort` | `"high"` | 自动选择的最高思考档位；只提供模型实际支持的档位 |
| `auto_model_candidates` | `{}` | 自动模型白名单，按 `chatgpt`、`deepseek` 分组；空对象采用当前服务的账户列表 |
| `model_timeout_seconds` | `null` | QQ 模型调用等待上限，整数 30～240 秒；`null` 或省略时沿用 ChatGPT 150 秒、DeepSeek 普通 55 秒／思考或自动选型 90 秒 |
| `deepseek_model` | `"deepseek-flash"` | DeepSeek 模型名 |
| `deepseek_key_file` | `".data/deepseek.key"` | 只包含 DeepSeek API Key 的 UTF-8 文件 |
| `data_dir` | `".data"` | ChatGPT 登录、设备标识、绑定、会话设置和记忆目录 |
| `owner_only` | `true` | 启用按会话绑定账号的权限检查；个人部署保留此值 |
| `group_members_can_chat` | `false` | 在绑定模式下，允许已绑定群的其他成员 @提问，管理设置仍限绑定账号 |
| `auto_chat` | `false` | 自动接话开关；开启后仍受消息接收权限、频率和每日上限限制 |
| `context_messages` | `100` | 每个会话保留的消息条数，范围 10～500，用户和助手消息都计数 |
| `context_idle_minutes` | `360` | 闲置多久后清除记忆，范围 0～10080 分钟；`0` 表示不过期 |

修改配置后需要重启。示例默认启用绑定检查，群成员使用通过 `group_members_can_chat` 单独开放。代码保留 `owner_only: false` 的群管理模式；该模式改变权限规则，普通部署沿用示例设置即可。

可以额外设置 `system_prompt` 字符串，定义机器人的表达风格。程序会继续追加 QQ 纯文本格式要求，以及启用搜索时的工具使用说明。

## 路径与数据

`bot.py` 将 `data_dir`、`deepseek_key_file` 和 `openai_key_file` 的相对路径解析到配置文件所在目录。例如 `--config /etc/qqbotgpt/config.json` 配合 `"data_dir": ".data"`，会使用 `/etc/qqbotgpt/.data`。服务器部署建议使用文档中的绝对路径。

`chatgpt.py` 独立运行，不读取机器人配置。其 `--data-dir` 默认是当前目录下的 `.data`。使用自定义数据目录时，登录和运行机器人需要指向同一位置：

```bash
python chatgpt.py --data-dir /path/to/data login
python bot.py --config /path/to/config.json
```

数据目录中的主要文件：

| 文件 | 内容 |
| --- | --- |
| `chatgpt.json` | ChatGPT 登录资料和可续期凭据 |
| `host.json` | 当前设备的独立标识 |
| `state.db` | QQ 绑定、会话设置、消息记忆、去重状态、有界附件引用索引及发送失败诊断记录 |
| `chatgpt-transfer.json` | 导出登录时生成的临时转移文件，导入和验证后删除 |

备份应包含配置和数据，并限制读取权限。群成员共享本群文字上下文，内容会随请求发送给所选模型；私聊和其他群使用各自的记录。附件引用索引包含平台下载地址及微信解密信息，按会话和发送者隔离；原始图片、文件不会写入聊天历史。`/清空` 删除当前会话保存的聊天记录、待处理附件和引用索引，并取消依赖旧上下文的排队任务。

## 设置优先级

模型服务和模型名按以下顺序确定：

1. 当前会话通过 `/模型` 保存的设置。
2. 本次启动的 `--provider` 和对应服务的配置。
3. 配置文件中的 `provider` 与对应模型名，空模型名按服务默认规则选择。

`--provider` 只覆盖本次启动的默认服务，不会写回配置。已有独立模型设置的会话发送 `/模型 默认` 后恢复默认模型选择和配置中的 `auto_model` 开关。

记忆设置和思考设置也按会话保存。`/记忆 默认` 恢复配置中的容量与过期时间，`/思考 默认` 恢复默认思考设置。ChatGPT 的可选档位取决于账户返回的模型能力；DeepSeek 支持 `/思考 开启`、`/思考 关闭` 和 `/思考 强度 高` 等命令，以 `/思考` 的说明为准。

DeepSeek 开启思考且启用过程展示时，QQ 将接口返回的 `reasoning_content` 单独展示为“DeepSeek 思考过程”，随后发送最终回答。模型未返回思考内容时只发回答。长思考最多拆为三条，不超过 QQ 每条 3000 字符的程序限制；更长部分会标记省略。与一分钟等待提示共用原消息的回复序号，最多五条。思考文本不进入聊天记忆；发生发送错误时，失败诊断会按原有期限保存对应思考内容。

微信复用相同的思考内容、分段格式和长度限制，先发思考再发回答。微信队列另行保存分段发送进度，重启后恢复待发送内容；成功完成后清理队列中的思考内容，聊天记忆只保留最终回答。具体重试行为见 [微信接入](微信接入.md)。

## 快速决策配置

`/模型 自动` 开启自动选择，`/模型 手动` 或 `/模型 自动 关闭` 关闭。每次选择只用于当次请求，保留原有手动模型和思考设置。直接指定模型或修改思考设置（含 `/思考 默认`）切回手动；`/思考 显示`、`/思考 隐藏` 仅控制展示。自动开关按会话保存在 SQLite 中，优先于 `auto_model` 配置，修改权限沿用模型设置规则。

`/频率 判断 开启` 和 `/频率 判断 关闭` 独立控制快速接话判断；`/频率 开启` 才会启动群聊自动接话。`/频率 默认` 同时恢复频率参数和 `auto_reply_decision` 的配置值。所有检查仍经过原有绑定、群成员权限、每日上限和冷却规则。两项决策同时需要时，使用一次 `POST /v1/decisions`，其中一个问题判断接话价值，另一个从合法的模型/强度组合中选择。私聊和明确 @不进行接话过滤。

默认绑定模式下，普通群消息仍只接收绑定账号的消息；`group_members_can_chat` 仅开放其他群成员的 @提问。快速接话判断只评估已通过这些权限检查的内容。还需要 QQ 平台实际下发普通群消息，只有 @事件的通道无法自动接话。

白名单示例（请替换为 `/模型 列表` 中实际可用的名称）：

```json
{
  "auto_model_candidates": {
    "chatgpt": ["gpt-6-luna", "gpt-6.1-sol", "gpt-6-astra"],
    "deepseek": ["deepseek-flash"]
  },
  "auto_model_max_effort": "high"
}
```

白名单与账户列表取交集，各服务仍使用各自凭据。强度上限支持 `none`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`；DeepSeek 只提供关闭思考及服务支持的 `low`、`high`、`max`。未知模型能力不从名称推断；无可调档位的模型保留默认。候选组合最多 255 个，超出或没有可用候选时沿用手动配置。模型选择置信度低于 0.4 也沿用手动设置，该初始阈值需在实际场景中评估。

快速判断只发送该会话最近最多 12 条文字、总计 6000 字符及附件类型，不主动添加附件下载地址、解密信息或原始文件。它看到的文字片段可能缺少较早的上下文，文件和图片内部难度也无法在此阶段评估。附件输入沿用已选 ChatGPT 模型，只自动调整强度。正式回答仍使用项目原有上下文与附件流程。

接话评分与模型选择置信度用于筛选，实际正确率需要用代表性群消息验证。`auto_reply_threshold` 默认 0.8，确认消息和结束话题优先保持安静。快速判断超时、服务拒绝、无效返回、缺少密钥或权限不足时不主动发言；明确提问的自动选型失败时继续用手动模型回答。关闭两项决策时完全沿用原有调用流程。

`gpt-6-luna` 的 Decisions 使用 OpenAI API Key 独立计费，ChatGPT 登录无法代替该密钥。`/状态` 显示最近一次决策结果、耗时、输入 token，以及最近生成回答实际使用的模型。普通日志不输出密钥、聊天正文或接口原始错误正文。服务器需要单独放置密钥并设置 `openai_key_file`，详细接口见 [Decisions 文档](https://developers.openai.com/api/docs/guides/decisions)。

## QQ 等待设置

QQ 中用 `/超时 240` 或 `/等待 240` 设置当前会话的等待上限，`/超时` 查看，`/超时 默认` 清除会话覆盖并恢复配置值。会话设置优先于 `model_timeout_seconds`，修改不需要重启。群聊与私聊分别保存，绑定模式下只有绑定账号可以修改。该项仅控制 QQ，微信和独立 ChatGPT 命令行保留原有行为。

上限从开始处理模型请求时计时，包含快速决策、凭据准备和附件读取；一分钟后仍未完成，向明确提问者发送一次等待提示，随后补发完整回答或超时提示。提示不会重置计时。程序同时限制从收到原消息到生成结束最多 270 秒，为 QQ 群聊五分钟回复窗口预留发送时间。排队耗时会缩短可用时间，超出窗口的排队消息会被跳过。

QQ 生成请求采用设置的总时限，不再受到原先 60 秒流式读取空闲上限的提前中断；登录、模型列表、附件下载等步骤仍保留各自的网络超时。到达总时限会取消本地任务并关闭连接，上游服务是否立即停止生成取决于其实现。

## 机器人命令行

| 命令 | 用途 |
| --- | --- |
| `python bot.py` | 按默认配置启动 |
| `python bot.py --config path/to/config.json` | 使用指定配置文件 |
| `python bot.py --bind` | 启动并生成一次本人绑定口令 |
| `python bot.py --new-binding` | 为新群生成一次性口令，然后退出；可和常驻服务同时运行 |
| `python bot.py --test-model` | 测试所选模型，不连接 QQ |
| `python bot.py --provider deepseek` | 本次启动默认使用 DeepSeek |

也可以通过环境变量 `QQBOT_CONFIG` 指定默认配置路径；显式的 `--config` 优先。多个命令行选项可以组合，例如 `python bot.py --config /etc/qqbotgpt/config.json --new-binding`。

`--bind` 可用于首次绑定和重新绑定，持有口令的账号会成为目标会话的绑定账号；绑定时会清空该会话旧记忆。`--new-binding` 仅用于尚未绑定的新群，已有绑定会保留。两种口令都只使用一次，10 分钟有效。

## ChatGPT 命令行

| 命令 | 用途 |
| --- | --- |
| `python chatgpt.py login` | 登录或继续现有账户授权 |
| `python chatgpt.py login --new` | 新建账户或工作区授权 |
| `python chatgpt.py login --no-browser` | 输出本机登录地址，由用户手动在同机浏览器打开 |
| `python chatgpt.py status` | 查看本机已保存的登录及额度管理入口 |
| `python chatgpt.py models` | 查看当前账户的可用模型 |
| `python chatgpt.py use <client_id>` | 选择已经保存的登录，随后重启机器人 |
| `python chatgpt.py test` | 发送一次独立模型连接测试 |
| `python chatgpt.py test --model <模型名> "你好"` | 用指定模型测试文字回答 |
| `python chatgpt.py test --search "联网查一下 Python 最新稳定版"` | 测试搜索，终端显示次数和来源 |
| `python chatgpt.py init-host` | 为当前设备准备独立标识 |
| `python chatgpt.py export --move` | 导出当前登录并停止本机使用该登录 |
| `python chatgpt.py import path/to/chatgpt-transfer.json` | 导入登录并保留目标设备标识 |

全局参数 `--data-dir` 放在子命令前，例如 `python chatgpt.py --data-dir /var/lib/qqbotgpt status`。迁移到服务器的完整步骤见 [服务器部署](服务器部署.md)。

思考过程展示默认隐藏，使用 `/思考 显示`、`/思考 隐藏` 独立切换，使用 `/思考 展示` 查看。设置按会话持久化，QQ 和微信共用规则；隐藏展示不改变模型思考模式或强度，`/思考 默认` 不重置展示设置。
